# Archive

Thư mục này giữ lại tài liệu cũ, báo cáo review đã resolved và bản nháp lịch sử. Không dùng các file trong đây làm source of truth nếu chưa đối chiếu lại với code hiện tại.

## Nhóm Tài Liệu

| Path | Nội dung |
| --- | --- |
| `legacy-root/` | Tài liệu tổng quan cũ ở root `module/` |
| `legacy-login-admin/` | Kế hoạch và phân tích cũ cho auth/admin |
| `legacy-order-module/` | Tài liệu triển khai/order flow/bug report cũ |
| `resolved-reports/` | Code review và architecture audit đã resolved |

## Quy Tắc

- Nếu cần trích dẫn lịch sử, ghi rõ nguồn từ archive.
- Nếu nội dung vẫn đúng và cần dùng thường xuyên, hãy rút gọn rồi đưa vào tài liệu hiện hành ngoài archive.
- Không thêm tài liệu mới vào archive trừ khi đó là báo cáo đã xử lý xong hoặc bản cũ được thay thế.
