# Skills Index

Thư mục này dành cho hướng dẫn kỹ năng nội bộ của agent khi làm việc với Maverik Store.

Hiện tại project chưa có skill tùy biến riêng cần tách thành file độc lập. Các quy tắc đang dùng nằm ở:

- `AGENTS.md`: safe-edit contract, giới hạn vùng chỉnh sửa, quy tắc không làm gãy code.
- `PROJECT_CONTEXT.md`: ngữ cảnh kiến trúc, luồng frontend/backend, module rủi ro cao.
- `docs/agents/CODEX_SAFE_EDIT_EXAMPLES.md`: ví dụ thao tác an toàn cho agent.

Khi thêm skill mới, tạo một file Markdown ngắn trong thư mục này, đặt tên theo mục tiêu cụ thể, ví dụ `backend-safe-edit.md` hoặc `frontend-ui-edit.md`.
